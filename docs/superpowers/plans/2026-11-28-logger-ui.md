# Tampilan Logger Gaya Badge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ganti UI log pesan dari rail `HH:MM:SS │ nama ~ chat` jadi gaya badge `[jam] [TIPE] nama(id) [REPLY] » pesan`, status kirim `↳ ✓ Terkirim → X · ms`, dan log tracing jadi `[jam] [tag] pesan` yang bisa dimatikan via `.env`.

**Architecture:** `lib/oktz-wa/ui.rs` merender semua baris (murni fungsi `baris_*` yang gampang dites + fungsi cetak tipis). `lib/oktz-wa/pipeline.rs` memanggilnya dengan tipe chat + deteksi reply. `lib/oktz-core/logging.rs` memasang formatter tracing custom. Warna lewat crate `owo-colors`.

**Tech Stack:** Rust edition 2024, `owo-colors` 4, `tracing-subscriber` (`env-filter`), `chrono`.

**Spec:** `docs/superpowers/specs/2026-11-28-logger-ui-design.md`

## Global Constraints

- Tanpa `owo_colors` di kode: TIDAK. Owner minta pakai `owo_colors` untuk badge + tag tracing.
- Raw SGR dihapus di jalur baru; `f()` + konstanta warna lama tetap ada demi pemanggil `sistem()` (bot.rs) yang tidak disentuh.
- Paritas pesan WhatsApp tidak berubah — perubahan murni console UI.
- Warna mati otomatis saat bukan tty atau `NO_COLOR` (perilaku `ui.rs` sekarang, dipertahankan).
- Komentar kode hanya kalau non-obvious (aturan AGENTS.md).
- `cargo fmt` + `cargo clippy` sebelum commit.

## Review Focus

- Teks badan pesan multi-baris: tiap baris harus dapat prefix `[jam] │`-less baru (gaya badge) tanpa kehilangan baris — uji string multi-baris.
- `[REPLY]` harus muncul HANYA kalau `contextInfo.quotedMessage` ada — uji true & false.
- Pesan non-command apa pun (termasuk teks sangat panjang / kosong) harus jadi `NoCmd`, bukan cetak penuh — uji `isi_log`.
- `OKTZ_LOG=off` tidak boleh panic/menulis apa pun; `RUST_LOG` harus tetap menang.
- `owo_colors::set_override(false)` (bukan tty) harus menghasilkan string polos tanpa kode ANSI — uji semua `baris_*`.
- target tracing tanpa `::` (mis. `Client/OfflineResume`) dan dengan `::` panjang harus jadi tag pendek yang benar.

impl TipeChat {
    fn badge(self) -> &'static str {
        match self {
            TipeChat::Private => "[PRIVATE]",
            TipeChat::Group => "[GROUP]",
            TipeChat::Channel => "[CHANNEL]",
            TipeChat::Status => "[STATUS]",
        }
    }
    fn gaya(self) -> Style {
        match self {
            TipeChat::Private => Style::new().on_truecolor(68, 114, 196).white().bold(),
            TipeChat::Group => Style::new().on_truecolor(16, 124, 65).white().bold(),
            TipeChat::Channel => Style::new().on_truecolor(155, 48, 255).white().bold(),
            TipeChat::Status => Style::new().on_truecolor(96, 96, 96).white().bold(),
        }
    }
}

Tambah `use owo_colors::OwoColorize;` + chrono. `ringkas_target`:
```rust
fn ringkas_target(target: &str) -> &str {
    target.rsplit("::").next().unwrap_or(target)
}
```
Struct formatter:
```rust
struct FormatRingkas;

impl<S, N> tracing_subscriber::fmt::FormatEvent<S, N> for FormatRingkas
where
    S: tracing::Subscriber + for<'a> tracing_subscriber::registry::LookupSpan<'a>,
    N: for<'a> tracing_subscriber::fmt::FormatFields<'a> + 'static,
{
    fn format_event(
        &self,
        ctx: &tracing_subscriber::fmt::FmtContext<'_, S, N>,
        mut w: tracing_subscriber::fmt::format::Writer<'_>,
        event: &tracing::Event<'_>,
    ) -> std::fmt::Result {
        let meta = event.metadata();
        let jam = chrono::Local::now().format("%H:%M:%S").to_string();
        let tag = format!("[{}]", ringkas_target(meta.target()));
        let tag = match *meta.level() {
            tracing::Level::ERROR => tag.red().bold(),
            tracing::Level::WARN => tag.yellow().bold(),
            tracing::Level::INFO => tag.cyan(),
            _ => tag.dimmed(),
        };
        write!(w, "{} {} ", format!("[{jam}]").bright_black(), tag)?;
        ctx.field_format().format_fields(w, event)?;
        writeln!(w)
    }
}
```
`init`:
```rust
pub fn init(level: &str) {
    INIT.call_once(|| {
        let dipilih = std::env::var("OKTZ_LOG")
            .ok()
            .filter(|v| !v.trim().is_empty())
            .unwrap_or_else(|| level.to_string());
        if dipilih.trim().eq_ignore_ascii_case("off") {
            return;
        }
        let filter = tracing_subscriber::EnvFilter::try_from_default_env()
            .unwrap_or_else(|_| tracing_subscriber::EnvFilter::new(&dipilih));
        let _ = tracing_subscriber::fmt()
            .event_format(FormatRingkas)
            .with_env_filter(filter)
            .try_init();
    });
}
```
